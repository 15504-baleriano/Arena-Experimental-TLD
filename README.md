
# Automated Experimental Arena Using TLD

## Description
Computer vision-based experimental arena automation
system using Tracking-Learning-Detection (TLD),
OpenCV, Python, and Arduino Mega.

## Main Features
- Real-time object tracking using TLD.
- Detection of virtual experimental zones.
- Automated liquid dispenser activation.
- Serial communication with Arduino.
- Experimental data export to CSV.
- Graphical user interface using Tkinter.

## Hardware
- Arduino Mega 2560
- USB camera
- Stepper motors
- ULN2003A motor drivers

## Software
- Python
- OpenCV with legacy tracking support
- Tkinter
- PySerial

## Validation
The system was technically evaluated using a
remote-controlled vehicle as a surrogate object,
rather than biological subjects.

## Installation
Install the compatible Python dependencies
listed in requirements.txt.

## Usage
Run the main Python application and configure
the camera, serial connection, and tracking region.
